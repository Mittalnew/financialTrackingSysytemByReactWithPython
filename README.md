# Fintrack

Personal finance tracker: **salary → spend → leftover**.

Track income and expenses, set category budgets, and see what’s left for the month — with a clear dashboard and basic analytics.

---

## Tech stack

| Layer | Tech |
|--------|------|
| Frontend | React, TypeScript, Vite |
| Routing | React Router |
| State | Redux Toolkit |
| Charts | Recharts |
| Styling | Tailwind CSS |
| Backend | FastAPI |
| Database | PostgreSQL (Neon) · SQLite fallback for local |
| Auth | JWT (access + refresh) + Resend email |
| Deploy | Docker · Render Blueprint (`render.yaml`) |

---

## Features

- **Dashboard** — leftover, tip, charts, budgets, recent activity + new-user onboarding  
- **Transactions** — add / edit / delete, filters, **CSV export**  
- **Analytics** — KPIs and charts  
- **Settings** — profile, budgets, change password  
- **Auth** — signup, email verify, password reset, refresh sessions, lockout, resend verify  

---

## Architecture

```
React UI  →  FastAPI  →  Neon Postgres
                ↓
             Resend (verify / reset emails)
```

Email verify/reset links hit the **API** (`/auth/verify-link`, `/auth/reset-link`) so they work even when the SPA is down.

## Local (npm + uvicorn)

1. Copy `.env.example` → `.env` and fill Neon / Resend if you want.  
2. Backend:

```bash
cd backend
python -m venv .venv
# Windows: .\.venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload --port 8003
```

3. Frontend (project root):

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:5173`.

Smoke (same DB as the API):

```bash
cd backend
.\.venv\Scripts\python scripts\smoke_auth.py http://127.0.0.1:8003
```

## Deploy on Render

Repo includes [`render.yaml`](render.yaml):

| Service | Type | Notes |
|---------|------|--------|
| `fintrack-api` | Web · **Docker** (`backend/Dockerfile`) | Neon + Resend env |
| `fintrack-web` | **Static** site | Build `npm ci && npm run build` |

### Steps

1. Push this repo to GitHub (already linked).  
2. Render → **New** → **Blueprint** → select this repo (or create services manually from the table above).  
3. Set env on **fintrack-api** (Dashboard → Environment):

| Key | Value |
|-----|--------|
| `DATABASE_URL` | Neon URI (`sslmode=require`) |
| `SECRET_KEY` | Auto-generated by Blueprint, or paste a long random string |
| `RESEND_API_KEY` | From Resend |
| `EMAIL_FROM` | `Fintrack <onboarding@resend.dev>` (or your domain) |
| `FRONTEND_URL` | `https://fintrack-web.onrender.com` (your static URL) |
| `API_PUBLIC_URL` | `https://fintrack-api.onrender.com` (your API URL) |
| `CORS_ORIGINS` | Same as `FRONTEND_URL` (comma-separated if several) |

4. Set env on **fintrack-web** (build-time):

| Key | Value |
|-----|--------|
| `VITE_API_URL` | `https://fintrack-api.onrender.com` |

5. Deploy → smoke: signup → email verify link → login → add transaction → logout.

**Free Render** services sleep when idle; first request can be slow. Resend free tier mainly emails your own address until you verify a domain.
